# Daily 7 Minutes

A gentle, wrist-friendly version of the classic 12-exercise "7-minute workout", designed for an older adult with wrist arthritis. Every exercise is done standing or in a chair: no weight on the hands or wrists (where the wall is used, only the elbows touch it), and no getting down on the floor.

Open `index.html` in a phone browser. An animated figure shows how to do each exercise at the right pace (`figures.js`; an orange dot marks where the elbows touch the wall). It talks you through each exercise, beeps for the last 3 seconds, keeps the screen awake, and tracks a daily streak on the device.
The goal is building muscle: strength moves use a slow tempo (about 3 seconds up, 3 seconds down), which builds muscle in older adults with bodyweight alone, and each exercise has a "Harder" version to progress to.

| Original | Replacement |
|---|---|
| Jumping jacks | Side-step jacks |
| Wall sit | Mini wall sit |
| Push-ups | Elbow wall push-ups |
| Crunches | Seated knee lifts |
| Step-ups | Slow step-ups |
| Squats | Slow chair sit-to-stands |
| Triceps dips | Wall angels |
| Plank | Elbow wall plank |
| High knees running | High-knee march |
| Lunges | Slow reverse step-backs |
| Push-up with rotation | Slow calf raises |
| Side plank | Standing side leg raises |
