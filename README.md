# Daily 7 Minutes

A gentle, wrist-friendly version of the classic 12-exercise "7-minute workout", designed for an older adult with wrist arthritis. Every exercise is done standing or in a chair: no weight on the hands or wrists, and no getting down on the floor.

Open `index.html` in a phone browser. It talks you through each exercise, beeps for the last 3 seconds, keeps the screen awake, and tracks a daily streak on the device.

| Original | Replacement |
|---|---|
| Jumping jacks | Side-step jacks |
| Wall sit | Mini wall sit |
| Push-ups | Forearm wall push-ups |
| Crunches | Seated knee lifts |
| Step-ups | Low step-ups |
| Squats | Chair sit-to-stands |
| Triceps dips | Wall angels |
| Plank | Forearm wall plank |
| High knees running | High-knee march |
| Lunges | Reverse step-backs |
| Push-up with rotation | Standing trunk twists |
| Side plank | Standing side leg raises |
